# 🙆 몸으로 말해요

로그인 없이 링크 하나로 친구들과 같이 하는 팀전 몸짓 전달 게임.

- 최대 5팀 · 팀 이름 지정 · 팀 인원 1~10명
- 팀원이 번호 자리(1번~마지막)를 골라 앉아요
- 팀마다 서로 다른 제시어, **1번만** 제시어를 보고 몸짓으로 전달 → **마지막 번호**가 정답 입력
- 점수: 정답 +2 · 가장 빨리 맞힌 팀 +1
- 한 폰으로 하기(제시어 뽑기) 모드 포함

## 실행
```
npm install
npm start   # http://localhost:3000
```

## Render 배포
이 저장소를 Render의 **New → Blueprint** 로 연결하면 `render.yaml` 대로 무료 웹 서비스가 만들어져요.
무료 서버는 15분간 접속이 없으면 잠들고, 잠들면 방 기록이 초기화돼요.
